# 週次 音声ジャーナル まとめタスク（ローカルExcel版）

## 概要
Googleドキュメント「R8音声ジャーナリング」の内容を読み取り、
新規エントリをJSON形式のみで出力する。Excelへの書き込みは別スクリプトが行う。

## 対象ファイル
- **ドキュメント ID**: `1L3FSmWiGNmoLeWv2rBYCXGQDtqXK3GIdHGDvG-J6Fho`

## 手順

### 1. ドキュメントを読み込む
`mcp__c267ad30-90c5-4d44-af1d-6ebb87c5be43__read_file_content` で
ドキュメント ID `1L3FSmWiGNmoLeWv2rBYCXGQDtqXK3GIdHGDvG-J6Fho` を読み込む。

### 2. 新規エントリを抽出する
- プロンプト冒頭の「前回まとめ日: X」以降に追加されたエントリのみ抽出する
- 「前回まとめ日: なし」の場合は全エントリを抽出する
- 日付は「◯月◯日」形式で記載されている
- 音声入力の誤りを修正する（例：「レッドバーペット」→レッドカーペット、「二十5番」→25番）

### 3. 通常記録と道徳記録を振り分ける
- `【道徳】` と記載されているエントリ → **道徳記録**として分類
- それ以外のエントリ → **通常の観察記録**として分類
- 出席番号は1〜29番
- **氏名は一切使用しない・参照しない**（個人情報保護のため）
- フォーマット：`・〇〇〇〇（M/D）`

### 4. JSON形式のみで出力する
説明文・前置き・後書きは一切書かず、以下のJSON**のみ**を出力する：

```json
{
  "matomeDate": "M/D",
  "newEntries": 追加件数,
  "observations": [
    {"番号": 出席番号, "内容": "・〇〇〇〇（M/D）", "日付": "M/D"}
  ],
  "moralEntries": [
    {"番号": 出席番号, "内容": "・〇〇〇〇（M/D）", "日付": "M/D"}
  ],
  "noRecords": [一度も記録がない出席番号のリスト],
  "staleRecords": [{"番号": N, "最終記録日": "M/D"}]
}
```

- 新規エントリがない場合は `observations` / `moralEntries` を空配列にする
- 同じ番号に複数エントリがある場合は `内容` を `\n` でつなぐ
- `日付` はその番号の最新エントリの日付

## 注意事項
- **個人名は絶対に使用しない**（名簿ファイルへのアクセス禁止）
- **データは外部に共有・送信しない**
- Googleドライブのファイルは読み取りのみ、書き込みは不要
- 音声入力の誤りはニュアンスに合うように自然な日本語に修正する
- 道徳記録は通知表の総合所見には使用しない
