# 給食配膳図の読み取り

都城学校給食センターが配る「配膳図」は、**同じ献立が学校ごとに違う日に出る**という、ひと目では読み違えやすい構造をしている。この表を、間違えずに読むための手順。

## いちばん大事なこと

**1行の中に日付が5つ並んでいる。そのうち自分の学校の日付は1つだけ。**

表の各行の左端には `A｜B｜C｜D｜E` の5列があり、それぞれに**別々の日付**が入っている。給食センターは同じ献立を5つのコースに日をずらして回しているため、こうなっている。

**乙房小学校は B コース。** つまり **B列の日付**を見る。

⚠ いちばん多い読み間違いは、**行の左端（A列）の日付を見てしまう**こと。A列は別の学校の日付で、たいてい乙房小より1〜2日ずれている。

他の学校について聞かれたときは、**表の下部にあるコース一覧（「Aコース…」「Bコース…」）を画像から読んで**、その学校がどのコースかを確かめてから列を選ぶ。記憶で答えない。

## 手順

### 1　画像を拡大してから読む

配膳図は紙を撮った写真やスクリーンショットで渡されることが多く、**そのままの解像度では日付や献立名を読み違える**。等倍で読もうとせず、必ず該当箇所を切り出して拡大する。

```bash
python3 scripts/zoom.py <画像パス> --region 0.0 0.13 0.5 0.35 --out /tmp/z1.png
```

`--region` は左上と右下を画像全体に対する比率（0〜1）で指定する。切り出した PNG を Read ツールで見る。狙いが外れたら比率を変えてやり直す。数回試すのが普通なので、1回で当てようとしなくてよい。

表はたいてい**左右2つの塊**に分かれて印刷されている。目的の日付が左側になければ、右側も必ず見る。

### 2　B列で目的の日付を探す

各行は3段になっている。

```
8/26  8/27  8/28  ← 日付
 日    日    日   ← 「にち」の字（読み飛ばしてよい）
 水    木    金   ← 曜日
```

B列（左から2番目）を上から順にたどり、目的の日付がある行を見つける。

**斜線（／）が引かれた日付欄**は、そのコースではその献立が出ない日を表す（月替わりの端でよく起きる）。斜線の行は飛ばす。

### 3　その行の「献立名」と「配膳図」を読む

- **献立名**欄：主食・牛乳・主菜・副菜・汁物が縦に並ぶ。**牛乳はほぼ毎日入っている**ので落とさない。
- **配膳図**欄：食器を置く位置が円で描かれ、牛乳パックの絵が添えられる。円の名前と**位置関係**（手前・奥・左・右）をそのまま読む。**太い線の円は平皿**（表の冒頭に「〇は平皿を表しています」と凡例がある）。細い円は椀・小鉢。
- **矢印**があることがある。「かける」の矢印はご飯にかけて食べる献立（カレー、ハヤシライス、他人丼など）を示す。
- 欄外の小さな囲みには、**地場産物**（例：ひなた宮崎県産【ピーマン】）、**行事食**（例：十五夜）、**郷土料理／名物料理／外国料理**の産地表示、**ゴミの扱い**（例：ジャムの袋はビニール袋に入れて返す）が入る。あれば拾う。

### 4　答える

読み取った内容だけを答える。表に書かれていないこと（栄養価、量、アレルゲンの有無）を推測で足さない。

## 出力の形

聞かれ方が軽ければ軽く答えてよい。「今日の給食は？」に対して表を丸ごと再現する必要はない。

```
【9月◯日（◯）の給食】※乙房小＝Bコース

・白ご飯
・牛乳
・麻婆豆腐
・中華和え

配膳：手前左にご飯、手前右に中華和え、奥に麻婆豆腐、右奥に牛乳
```

特記事項があるときだけ、最後に1行足す。

```
※【ピーマン】はひなた宮崎県産
```

複数日をまとめて聞かれたときは表にする。

## 実例（令和8年度 8・9月分・8月28日）

該当行は、日付欄がこうなっている。

```
A     B      C   D   E
8/27  8/28   ／  ／  ／
 日    日
 木    金
```

A列は 8/27。**ここを読むと1日ずれる。** B列の 8/28（金）が乙房小の日。
C・D・E は斜線なので、そのコースはこの献立を実施しない。

献立名欄：白ご飯／牛乳／マーボー豆腐／中華和え
配膳図：手前左に「ご飯」、奥に太線の円で「中華和え」（平皿）、右に「マーボー豆腐」、右上に牛乳。

答え方：

```
【8月28日（金）の給食】※乙房小＝Bコース

・白ご飯
・牛乳
・マーボー豆腐
・中華和え

配膳：手前左にご飯、奥に中華和え（平皿）、右にマーボー豆腐、右上に牛乳
```

## つまずきやすい点

| | 対処 |
|---|---|
| A列の日付を読んでしまう | **B列**（左から2番目）を数えて確認する。列を見失ったら見出しの `A B C D E` まで戻る |
| 目的の日が見つからない | 左の塊しか見ていない可能性が高い。**右の塊**も見る |
| 日付がぼやけて読めない | 拡大が足りない。`zoom.py` の領域を狭くしてもう一度 |
| 献立が1品足りない | 牛乳を落としていないか。献立名欄は上から順に全部読む |
| 斜線の行を献立として読んでしまう | 斜線＝そのコースは実施なし。次の行を見る |

## 年度・月がまたぐとき

配膳図は「令和◯年度 ◯・◯月分」と月ごとに配られる。**渡された画像がどの期間のものかを最初に確認**し、聞かれた日付がその期間に入っていなければ、その旨を伝えて別の月の配膳図を求める。手元の表から外挿しない。
